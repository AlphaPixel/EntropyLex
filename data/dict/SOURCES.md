# Candidate dictionary sources

This is the working inventory of data that may be used to select EntropyLex dictionary tokens. A source appears here only when its stated terms permit relevant use or make it a conditional candidate. Listing a source does not mean it has been selected, and a generated dictionary must still satisfy every license condition that applies to its input data.

Each count uses the unit provided by that source. These units are not interchangeable: one written word may have several pronunciation records, one spell-checker entry may generate several grammatical forms, and a filtering pattern may match several spellings. **Measured** counts were calculated from the named download. **Published** counts come from the source project's documentation. Before actual use, the pipeline must identify an unchangeable release or exact repository commit, download it again, record its SHA-256 checksum, count the records successfully loaded, and review the complete license text. A SHA-256 checksum is a fixed-size identifier calculated from every byte in the downloaded file; it lets a later run confirm that it received the same bytes.

Reviewed 2026-08-17. This is a preliminary technical review of stated license terms, not legal advice or a final redistribution decision.

The MIT license on EntropyLex software applies only to this repository's own software and text. It does not replace the licenses of imported data. A published dictionary will need its own notices and attributions. If selection uses ShareAlike data, the project must first determine which license must apply to the resulting dictionary.

Terms used below:

- A **lemma** is a base word form, such as “walk” for “walks” and “walked.” A **headword** is the form under which a dictionary lists an entry.
- A **part of speech** is a grammatical category such as noun, verb, or adjective.
- A **synset** is a group of words representing one meaning in WordNet.
- An **affix rule** describes how a prefix or suffix generates additional written forms from one spell-checker entry.
- A **semantic vector** is a list of numbers representing a word's usage context so software can estimate similarity in meaning.
- A **blocklist** identifies terms or patterns to exclude. A pattern may match more than one spelling and is not itself necessarily a candidate word.
- **CC BY** requires attribution. **CC BY-SA** additionally requires adapted material to use the same or a compatible license. MIT and Apache 2.0 generally permit broad reuse when their required notices are retained. PDDL is the Open Data Commons Public Domain Dedication and License for databases. The exact source license always controls.

## Sources not accepted merely because they are downloadable

- A GitHub repository without an explicit data license is not a usable source.
- “Free for research” or noncommercial data is not suitable for a generally redistributable EntropyLex dictionary.
- Frequency lists derived from search engines or commercial text collections require their own redistribution review. A separate project that mentions or uses them cannot grant EntropyLex permission.
- Large word lists created for word games are not automatically suitable. Their counts often include rare, historical, specialized, grammatical, or invented forms that conflict with EntropyLex's familiarity requirement.
- A broadly reusable extraction program does not change the license of the data it reads. Material extracted from Wiktionary or Wikipedia remains subject to the applicable source terms. A separately published trained model such as GloVe follows the terms stated for that model.
